# proj-3-embedded

The players have to work together to diffuse a bomb. On both screens the players will see color labels above their m5core2 buttons ("wires") and rules on their screen telling them which wires must and must not be cut (i.e. "cut all blue wires, don't cut any middle wires"). 
Rules may conflict, and if they do, "should not" rules overrule "should" rules. Tapping the m5core2 button cuts the wire. When the players believe they have cut all of the correct wires, they both must agree through their own input that every correct wire has been cut to end the game.

Win condition:Both players agree to end the game after cutting only every correct wire.

Loss conditions: Any player cuts the wrong wire. Players run out of time. Players end the game without cutting all of the correct wires."
